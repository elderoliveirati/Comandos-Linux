    Compactação e pacotes

    12. Compactação e descompactação¶

    tar.gz¶

    Criar:

    tar -czvf arquivo.tar.gz diretorio/

    Extrair:

    tar -xzvf arquivo.tar.gz

    Listar conteúdo:

    tar -tzvf arquivo.tar.gz

    gzip¶

    gzip arquivo
gunzip arquivo.gz

    13. Gerenciamento de pacotes — Ubuntu/Debian¶

    Atualizar índice¶

    sudo apt update

    Atualizar pacotes¶

    sudo apt upgrade

    Instalar¶

    sudo apt install pacote

    Remover¶

    sudo apt remove pacote

    Procurar pacote¶

    apt search pacote

    Ver pacote instalado¶

    dpkg -l | grep pacote

    14. Gerenciamento de pacotes — RHEL/AlmaLinux/Rocky¶

    Atualizar¶

    sudo dnf update

    Instalar¶

    sudo dnf install pacote

    Remover¶

    sudo dnf remove pacote

    Procurar¶

    dnf search pacote

    Ver pacote instalado¶

    rpm -qa | grep pacote
