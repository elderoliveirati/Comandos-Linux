    1. Navegação pelo sistema de arquivos¶

    Diretório atual¶

    pwd

    Listar arquivos¶

    ls
ls -l
ls -lh
ls -la
ls -lhat
    • -l — formato detalhado
    • -h — tamanhos legíveis
    • -a — inclui arquivos ocultos
    • -t — ordena por data
    • -r — ordem reversa

    Entrar em um diretório¶

    cd /caminho/do/diretorio
cd ..
cd ~
cd -

    Criar diretório¶

    mkdir nome_diretorio
mkdir -p /caminho/estrutura/completa

    Criar arquivo vazio¶

    touch arquivo.txt

    Copiar¶

    cp arquivo.txt destino/
cp -r diretorio/ destino/

    Mover ou renomear¶

    mv arquivo.txt destino/
mv arquivo_antigo.txt arquivo_novo.txt

    Remover arquivo¶

    rm arquivo.txt

    Remover diretório vazio¶

    rmdir diretorio

    Remover diretório e conteúdo¶

    rm -r diretorio

    Evite rm -rf sem verificar cuidadosamente o caminho.

    2. Localizar arquivos e diretórios¶

    Procurar pelo nome¶

    find /caminho -name "arquivo.txt"
find /caminho -iname "*.sql"
find / -type d -name "postgresql"

    Procurar somente arquivos¶

    find /caminho -type f -name "*.log"

    Procurar arquivos modificados recentemente¶

    find /caminho -type f -mtime -1

    Procurar arquivos grandes¶

    find / -type f -size +1G 2>/dev/null

    Descobrir onde está um comando¶

    which psql
whereis psql

    3. Visualização e edição de arquivos¶

    Mostrar conteúdo¶

    cat arquivo.txt
less arquivo.txt
more arquivo.txt

    Primeiras linhas¶

    head arquivo.txt
head -n 20 arquivo.txt

    Últimas linhas¶

    tail arquivo.txt
tail -n 50 arquivo.txt

    Acompanhar log em tempo real¶

    tail -f /caminho/arquivo.log

    Editar com nano¶

    nano arquivo.txt

    Editar com vi/vim¶

    vi arquivo.txt
vim arquivo.txt

    4. Pesquisa dentro de arquivos¶

    Procurar texto¶

    grep "postgres" arquivo.txt
grep -i "erro" arquivo.log

    Procurar recursivamente¶

    grep -R "texto" /caminho

    Mostrar número da linha¶

    grep -n "erro" arquivo.log

    Combinar comandos¶

    cat arquivo.log | grep "ERROR"

    Ou, de forma mais direta:

    grep "ERROR" arquivo.log
