    34. Comandos migracao database PostgreSQL¶

    Máquina antiga¶

    ssh elder.oliveira@IP_MAQUINA_ANTIGA

    Mover para pasta temporaria¶

    cd /temp/

    Gerar arquivo de backup em formato texto¶

    pg_dump -U postgres -d #database_nome > #database_nome.sql

    Listar arquivos detalhadamente¶

    ls -lhat

    Mover arquivo para pasta especifica caso necessário¶

    mv #database_nome.sql /tmp/

    Nova Máquina¶

    ssh elder.oliveira@IP_MAQUINA_NOVA

    Logar com postgres¶

    psql -U postgres -l

    Organizar repositorio para migracoes do dia¶

    cd /backups/
mkdir migracao_pgbanco_"DATA_DIA_MIGRACAO"
cd /migracao_pgbanco_"DATA_DIA_MIGRACAO"

    Transferir arquivo para nova máquina¶

    scp elder.oliveira@IP_MAQUINA_ANTIGA:/tmp/#database_nome.sql .

    Criar database¶

    psql -c "create database #database_nome;"

    Restaurar arquivo de backup¶

    psql -d #database_nome < #database_nome.sql

    Criar usuário e aplicar owner¶

    create user #usuario_nome with #login password '*';
alter database #database_nome owner to #usuario_nome;

    Definir privilégios para objetos já existentes¶

    grant all privileges on database #database_nome to #usuario_nome
grant all privileges on all tables in schema public to #usuario_nome;
grant all privileges on all sequences in schema public to #usuario_nome;
grant all privileges on all functions in schema public to #usuario_nome;

    Definir privilégios para objetos futuros¶

    alter default privileges in schema public
grant all on tables to #usuario_nome

alter default privileges in schema public
grant all on sequences to #usuario_nome

alter default privileges in schema public
grant all on functions to #usuario_nome

    Passos finais¶

    Liberar IP no pg_hba_conf
Passar IP, usuario e senha 
Atualizar o arquivo de configuração da aplicação

    Recarregar arquivo de configuração¶

    sudo -u postgres psql -c "SELECT pg_reload_conf();"

    35. Comandos opcionais¶

    Listar tabelas da base¶

    \ dt+

    Conectar psql a banco específico¶

    \c #database_nome

    Testar conexão do PostgreSQL com a aplicação¶

    RAILS_EW=production bundle exec rails runner "puts ActiveRecord::Base.connection.execute('SELECT version()')"

    Criar links simbólico¶

    ln -s /var/lib/pgsql/data/pg_hba.conf pg_hba.conf
